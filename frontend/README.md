# Frontend

## Overview

The frontend provides a modern and interactive interface for auditors to upload invoices, review validation results, and monitor risk analysis.

## Responsibilities

- Invoice upload interface
- Dashboard
- Risk visualization
- Invoice detail page
- AI explanation display
- Report download

## Planned Tech Stack

- React
- Vite
- Tailwind CSS
- shadcn/ui
- Axios
- Recharts

## Planned Features

- Upload invoices
- View extracted invoice details
- Risk score dashboard
- Interactive charts
- Search & filter invoices
- Download audit reports
