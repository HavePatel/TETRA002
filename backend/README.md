# Backend

## Overview

The backend powers the AI-Powered Invoice Risk Scanner by handling invoice processing, validation, risk analysis, and communication with AI services.

## Responsibilities

- File upload handling
- Invoice data processing
- Business rule validation
- Risk score calculation
- AI integration
- REST API development
- Database interactions

## Planned Tech Stack

- FastAPI
- Python
- Pandas
- Pydantic
- SQLite / PostgreSQL
- Gemini API
- PaddleOCR
